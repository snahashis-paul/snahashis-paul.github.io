# Snahashis Paul — DevOps Portfolio

Graduate and junior DevOps portfolio covering AWS EKS, Terraform, Kubernetes, GitOps, CI/CD and platform reliability.

Website: https://snahashis-paul.github.io/

## Files

- index.html: portfolio content
- styles.css: responsive styling
- app.js: case-study filters and copy-email interaction
- assets/: downloadable CV and favicon

Hosted using GitHub Pages from the root of the main branch. No installation or build step is needed.
